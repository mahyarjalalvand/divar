# فرانت‌اند دیوار

[English](README.md)

رابط کاربری پروژه «دیوار» با React و TypeScript ساخته شده است. کاربران می‌توانند آگهی‌ها را ببینند و بر اساس دسته‌بندی فیلتر کنند، با شمارهٔ موبایل و رمز یک‌بارمصرف وارد شوند و آگهی‌های خود را مدیریت کنند. این پروژه همچنین پنل مدیریت دسته‌بندی‌ها را برای کاربران دارای نقش مدیر فراهم می‌کند.

## قابلیت‌ها

- نمایش فهرست آگهی‌ها همراه با تصویر، عنوان، قیمت و شهر
- دریافت و فیلتر آگهی‌ها بر اساس دسته‌بندی
- ورود دومرحله‌ای با شمارهٔ موبایل و کد یک‌بارمصرف (OTP)
- نگه‌داری توکن‌های دسترسی و نوسازی خودکار نشست با refresh token
- محافظت از مسیرهای کاربر و محدودسازی پنل مدیریت به نقش `ADMIN`
- ثبت آگهی جدید شامل عنوان، توضیحات، قیمت، شهر، دسته‌بندی و تصویر
- نمایش و حذف آگهی‌های ثبت‌شدهٔ کاربر
- ایجاد، نمایش و حذف دسته‌بندی‌ها در پنل مدیریت
- نمایش وضعیت بارگذاری، خطا و اعلان‌های موفقیت یا خطا
- رابط راست‌به‌چپ فارسی با فونت Vazirmatn
- صفحهٔ 404 برای مسیرهای نامعتبر

## فناوری‌ها

- React 19 و TypeScript
- Vite 7
- React Router 7
- TanStack Query 5 برای دریافت، کش و همگام‌سازی داده‌ها
- Tailwind CSS 4
- Sonner برای اعلان‌ها و Lucide React برای آیکن‌ها
- ESLint

## پیش‌نیازها

- Node.js نسخهٔ `20.19.0` یا بالاتر، یا `22.12.0` یا بالاتر
- npm
- اجرای API بک‌اند پروژه؛ آدرس پیش‌فرض آن `http://localhost:3400/` است.

## راه‌اندازی

وارد پوشهٔ فرانت‌اند شوید و وابستگی‌ها را نصب کنید:

```bash
cd front-end
npm i
```

فایل `.env` را در همین پوشه ایجاد کنید:

```env
VITE_BASE_URL=http://localhost:3400/
```

مقدار `VITE_BASE_URL` باید با `/` تمام شود. سپس سرور توسعه را اجرا کنید:

```bash
npm run dev
```

نشانی برنامه در خروجی Vite نمایش داده می‌شود و معمولاً `http://localhost:5173/` است.

## اسکریپت‌ها

| دستور             | توضیح                                                |
| ----------------- | ---------------------------------------------------- |
| `npm run dev`     | اجرای سرور توسعه با بارگذاری مجدد خودکار             |
| `npm run build`   | بررسی نوع‌ها و ساخت نسخهٔ production در پوشهٔ `dist` |
| `npm run preview` | پیش‌نمایش محلی خروجی production                      |
| `npm run lint`    | بررسی کد با ESLint                                   |

## مسیرهای برنامه

| مسیر         | توضیح                            | دسترسی                                          |
| ------------ | -------------------------------- | ----------------------------------------------- |
| `/`          | نمایش آگهی‌ها و دسته‌بندی‌ها     | عمومی                                           |
| `/auth`      | ورود با شمارهٔ موبایل و OTP      | مهمان؛ کاربران واردشده به داشبورد هدایت می‌شوند |
| `/dashboard` | ثبت، مشاهده و حذف آگهی‌های کاربر | نیازمند ورود                                    |
| `/admin`     | مدیریت دسته‌بندی‌ها              | فقط کاربر با نقش `ADMIN`                        |
| `*`          | صفحهٔ پیدا نشد                   | عمومی                                           |

## اتصال به API و احراز هویت

همهٔ درخواست‌ها با آدرس تنظیم‌شده در `VITE_BASE_URL` ارسال می‌شوند. پس از تأیید OTP، توکن دسترسی و refresh token در کوکی مرورگر ذخیره می‌شوند. درخواست‌های احراز هویت‌شده توکن دسترسی را در هدر `Authorization: Bearer <token>` می‌فرستند. در صورت دریافت پاسخ `401`، برنامه یک‌بار تلاش می‌کند توکن را با refresh token نوسازی کرده و درخواست را دوباره ارسال کند.

مهم‌ترین endpointهای استفاده‌شده در فرانت‌اند:

- `POST /auth/send-otp`
- `POST /auth/check-otp`
- `POST /auth/check-refresh-token`
- `GET /user/whoami`
- `GET /`
- `GET /post/my`
- `POST /post/create`
- `DELETE /post/delete/:id`
- `GET /category`
- `POST /category`
- `DELETE /category/:id`

## ساختار پروژه

```text
src/
├── assets/       # فونت‌ها و فایل‌های ثابت
├── components/   # کامپوننت‌های رابط کاربری و قالب‌ها
├── config/       # پیکربندی کتابخانه‌ها، از جمله React Query
├── layouts/      # چیدمان مشترک، هدر و فوتر
├── pages/        # صفحه‌های اصلی برنامه
├── router/       # مسیرها و کنترل دسترسی
├── services/     # ارتباط با API
├── styles/       # استایل‌های سراسری و فونت‌ها
├── types/        # نوع‌های TypeScript
├── utils/        # توابع کمکی، مانند مدیریت کوکی‌ها
├── App.tsx       # Providerها و ساختار اصلی برنامه
└── main.tsx      # نقطهٔ ورود برنامه
```

## ساخت نسخهٔ production

پیش از استقرار، `VITE_BASE_URL` را روی آدرس API محیط مقصد قرار دهید و سپس اجرا کنید:

```bash
npm run build
npm run preview
```
